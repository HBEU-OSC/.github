## 社团简介
湖北工程学院开放原子社团是一个致力于促进开源文化发展、贡献优秀开源软件的活跃校园开源社区。我们立足湖北工程学院，连接开放原子开源生态，倡导开放、协作、共享、创新的开源精神，鼓励成员了解开源、参与开源、共创开源。我们坚信开源文化的重要性，相信共同的开源目标将会使我们变得更加强大和有影响力。

## 关于我们

我们是一个由 湖北工程学院 学生组成的开源社团，致力于推广开源文化、培养开源贡献者。我们相信 **开放、协作、分享** 的力量，希望通过技术社区连接更多志同道合的人。

无论你是刚接触开源的新手，还是经验丰富的贡献者，这里都欢迎你。

## 我们在做什么

- 定期举办开源入门工作坊和技术分享会
- 孵化社团自己的开源项目
- 参加开源社区的活动和比赛
- 做一些有趣的文创周边
- 帮助新成员完成第一次开源贡献
